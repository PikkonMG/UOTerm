# Inspect playbook

1. `observe` for the radar and nearby mobiles. Optional `size` (5-41, default 21) widens the radar. CLI `uoterm look` is the same snapshot at size 21.
2. `single_click` a mobile or item to ask its name. Wait for the name in the journal.
3. `look_around` for a wider scene. `find_mobiles` / `find_items` to search.
4. `map_tile` and `can_walk` before you step into a tile you do not trust.

Names on first sight are often empty. Click before you hunt or buy by name.
