# Runebook playbook

A runebook recalls to a stored rune. Charges come from recall scrolls dropped onto the book.

1. `use` the book. Read the gump. Slot buttons recall. Do not guess numbers: read the line beside each button.
2. Stand still for the cast. Wait for a location jump. `map_changed` if the rune is on another map.
3. To charge: `drop` recall scrolls onto the book.
4. To fill: mark a rune where you stand (`use` a mark scroll, target the rune), then `drop` the rune onto the book.
5. Close extra gumps before you press a slot, so the press hits this book.

Recall fails when overweight, in a house you do not own, or when the shard forbids the facet.
